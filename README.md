# Educação Financeira

Repositório de apoio para aulas e estudos de **educação financeira**, com materiais introdutórios, conceitos de planejamento financeiro, investimentos e conteúdos específicos para trabalhar o tema com crianças.

> **Objetivo:** reunir conteúdos em Markdown que possam ser usados como leitura prévia, referência para aulas, atividades e estudos independentes.

## Sequência sugerida para estudo

1. **Reconhecer escolhas financeiras:** bens, serviços, necessidades e desejos.
2. **Criar hábitos saudáveis:** poupança, metas e orçamento.
3. **Entender o sistema financeiro:** bancos, contas, corretoras e custos.
4. **Conhecer investimentos:** liquidez, risco, retorno e diversificação.
5. **Explorar temas específicos:** previdência, criptoativos e análise de investimentos.
6. **Aplicar o aprendizado:** analisar situações fictícias e justificar decisões.

A sequência é uma sugestão didática; os conteúdos podem ser adaptados à faixa etária, à carga horária e aos objetivos de cada turma.

## Como usar

1. Abra um dos materiais pelos links acima.
2. Use o conteúdo como leitura, base para slides ou ponto de partida para uma atividade.
3. Adapte exemplos, vocabulário e complexidade ao público.
4. Confira datas, regras e dados que possam mudar antes de utilizar o material em aula.

## Aviso educacional

Os materiais têm finalidade educativa e não constituem recomendação individual de investimento, orientação tributária ou jurídica. Produtos, taxas, regras de tributação, proteção de depósitos e condições de mercado podem mudar. Consulte fontes oficiais e documentos atualizados antes de tomar decisões ou ensinar regras vigentes.

## Manutenção

Este repositório está em evolução. Sugestões de correção, atualização de fontes e novas atividades são bem-vindas por meio de issues ou pull requests.
