## Orientação de uso

Os arquivos podem servir como leitura de apoio, referência para preparar aulas ou ponto de partida para atividades. Adapte os exemplos à faixa etária e aos objetivos de aprendizagem.

## Aviso educacional

Este repositório tem finalidade educativa e não constitui recomendação individual de investimento, orientação tributária ou jurídica. Taxas, regras de tributação, condições dos produtos e garantias podem mudar. Consulte fontes oficiais e documentos atualizados antes de tomar decisões financeiras.
